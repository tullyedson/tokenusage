# Contributing

Fork the repository, create a branch for your change, and open a pull request against `main`.

Pull requests are proposals. They remain outside the main codebase until the repository owner reviews and explicitly chooses to merge them. Automatic merging is disabled. New commits invalidate earlier approvals, and every file is covered by the owner's CODEOWNERS rule.

Include a description of the change and the checks you ran. Provider additions should follow [Adding providers](docs/ADDING_PROVIDERS.md). Never submit credentials, browser profiles or personal account data.

Maintainers and automated tools must use pull requests. Do not merge a contribution or bypass repository protections without the owner's explicit approval for that action.
